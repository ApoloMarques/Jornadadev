# Exercício 04 – Campo customizado na SA1

## Objetivo

Criar um campo customizado na tabela SA1 seguindo o padrão do campo A1_VOVO criado em aula.

## Campo criado

- Campo: A1_XAPELID
- Tipo: Character
- Tamanho: 50
- Contexto: Real
- Propriedade: Alterar

## Informações

- Título: APELIDO
- Descrição: APELIDO DO CLIENTE
- Help: Informe o apelido do cliente.

## Resultado

O campo foi criado com sucesso no dicionário de dados (SX3), seguindo o mesmo padrão utilizado para o campo A1_VOVO.

Foi realizada a validação no SmartClient. No ambiente utilizado, o novo campo não foi exibido automaticamente na tela de cadastro de clientes, indicando que a rotina utiliza um layout próprio para apresentação dos campos.
