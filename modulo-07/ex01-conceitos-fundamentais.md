# Exercício 01 – Conceitos Fundamentais

## a. Qual é a função do AppServer?

O AppServer é o servidor de aplicação do Protheus. Ele processa as solicitações feitas pelo SmartClient, executa as regras de negócio e faz a comunicação com o banco de dados, garantindo o funcionamento do sistema.

---

## b. O que é o RPO?

O RPO (Repository) é um repositório que armazena os programas compilados do Protheus. É nele que ficam as rotinas que o AppServer executa quando o usuário utiliza o sistema.

---

## c. Para que serve o Configurador (SIGACFG)?

O Configurador (SIGACFG) é o módulo utilizado para administrar e personalizar o Protheus. Nele é possível criar tabelas, campos, usuários, permissões e realizar configurações do sistema.

---

## d. Qual a diferença entre campo Real e campo Virtual no SX3?

O campo Real é armazenado fisicamente na tabela do banco de dados. Já o campo Virtual não é gravado na tabela; seu valor é calculado ou obtido durante a execução do sistema, sendo utilizado apenas quando necessário.
