# 🐾 Projeto em Destaque

## Sistema de Cadastro de Pets no ERP Protheus

Durante o Módulo 08 desenvolvi uma rotina completa para gerenciamento de Pets utilizando **ADVPL** e recursos do **ERP Protheus**.

O projeto foi construído seguindo o fluxo de desenvolvimento utilizado em ambientes Protheus, desde a configuração do dicionário de dados até a criação da interface de cadastro e consulta.

### Recursos implementados

✅ Tabela customizada (ZA2)

✅ Campos personalizados (SX3)

✅ Índices (SIX)

✅ Cadastro utilizando **AxCadastro**

✅ Consulta utilizando **mBrowse**

✅ Campo Virtual

✅ Validação de Cliente com `ExistCpo()`

✅ Legendas coloridas

✅ Gatilhos (SX7)

✅ Preenchimento automático de endereço por CEP

✅ Filtro de registros do mês

✅ Botão personalizado **Sem Filtro**

✅ Organização das evidências de execução
