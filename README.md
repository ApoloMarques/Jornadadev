# 🚀 Sobre mim

Sou estudante de Desenvolvimento de Software e participante da **Jornada DEV START — Programa START (TOTVS Paulista)**.

Este repositório foi criado para documentar minha evolução prática em programação, reunindo exercícios, desafios, códigos-fonte e evidências desenvolvidas durante a formação.

Minha jornada começou pelos fundamentos de lógica de programação e Harbour, avançando para **ADVPL**, arquitetura do **ERP Protheus**, dicionário de dados e desenvolvimento de rotinas executadas em ambiente Protheus.

Meu foco é construir uma base técnica sólida, escrever códigos organizados e funcionais e me preparar para oportunidades profissionais como **Desenvolvedor ADVPL/Protheus**.

Acredito que consistência, prática, organização e atenção aos detalhes são fundamentais para construir uma carreira sólida em tecnologia.

# 🐾 Projeto em Destaque

## Sistema de Cadastro de Pets no ERP Protheus

Durante o Módulo 08 desenvolvi uma rotina completa para gerenciamento de Pets utilizando **ADVPL** e recursos do **ERP Protheus**.

O projeto foi construído seguindo o fluxo de desenvolvimento utilizado em ambientes Protheus, desde a configuração do dicionário de dados até a criação da interface de cadastro e consulta.

### Recursos implementados

✅ Tabela customizada (ZA2)

✅ Campos personalizados (SX3)

✅ Índices (SIX)

✅ Cadastro utilizando **AxCadastro**

✅ Consulta utilizando **mBrowse**

✅ Campo Virtual

✅ Validação de Cliente com `ExistCpo()`

✅ Legendas coloridas

✅ Gatilhos (SX7)

✅ Preenchimento automático de endereço por CEP

✅ Filtro de registros do mês

✅ Botão personalizado **Sem Filtro**
